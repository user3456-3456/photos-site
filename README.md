# Moments I Kept

A photography portfolio landing page featuring wildlife photos from Nairobi National Park.

**Author:** Damian
**Live site:** [](https://github.com/user3456-3456/photos-site)

## Description

Moments I Kept is a one-page photo journal. It has an introduction, a short bio of the author, a list of favorite photos with links to each one, and a contact form. I built it with plain HTML and CSS as my second-week project while learning web development.

## Features

- Responsive layout that works on phones and desktops
- Ordered list of favorite photos, each linking to its photo section
- Custom CSS stylesheet with hover effects
- Contact form with validation
